이유영 첫돌 모바일 초대장 - 공개 링크 배포용

1. 이 폴더 전체를 Vercel / Netlify / GitHub Pages 등에 업로드하세요.
2. 배포 후 생성된 https://... 주소가 실제 초대장 링크입니다.
3. 그 주소를 카카오톡에 붙여넣으면 상대방이 클릭해 바로 초대장을 열 수 있습니다.
4. 초대장 내부 '복사' 버튼은 배포된 현재 주소(window.location.href)를 자동으로 복사합니다.

중요:
- sandbox:/mnt/data/... 주소는 ChatGPT 내부 주소라 카카오톡 공개 공유용으로 사용할 수 없습니다.
- 반드시 HTTPS로 공개 배포되어야 합니다.
